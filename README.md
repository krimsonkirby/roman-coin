# Roman Emperor Coin Collection

A coin for every Roman emperor, Julius Caesar to Romulus Augustulus.

- `index.html` — the collection tracker (one self-contained page). Your ticks, notes and photos are saved in your own browser; use **Save full copy** to back up or move devices, and **Export showcase** for a view-only copy to share.
- `prices.json` — cheapest current listings for coins still needed, refreshed every Tuesday evening (Brisbane time) by Claude. The page loads it automatically.
